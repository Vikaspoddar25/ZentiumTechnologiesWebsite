## Known technical notes

- The global npm cache was root-owned on the original dev machine. If `npm install`
  fails with `EACCES`, run `sudo chown -R 501:20 ~/.npm` once.
- `AGENTS.md` and `CLAUDE.md` are auto-generated by `next dev`. Leave them committed.
- ESLint uses the flat config from `eslint-config-next/core-web-vitals` — don't
  reintroduce `FlatCompat`, it crashes with v16.
- The Vercel framework preset is pinned in `vercel.json`. The project was originally
  created against an empty repo, so Vercel auto-detected it as "Other", served
  `public/` and 404'd every route. Don't change the preset in the dashboard.
- `linkedin/` is gitignored — those exports contain private phone numbers and emails,
  and the repository is public.
- Animations use `whileInView`, which does not fire in background browser tabs. If a
  page looks blank in an automated/headless check, verify in a visible window first.
